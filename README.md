# ERP API

Minimal ERP REST API portfolio project.

- JavaScript / Node.js / pnpm
- Express / PostgreSQL / raw SQL
- Modular monolith with full OOP, DI, SOLID
- JWT + Argon2 + RBAC
- Transactions, inventory, sales

## Quick start

```bash
cp .env.example .env
pnpm install
pnpm db:migrate
pnpm dev
```
